## [0.4.1] - 2026-10-25

### Changed

- The browser bundle no longer includes ajv or compiles the schema at runtime. `lib/validate.js` uses a validator generated from `schema/drumdrom.schema.json` by ajv standalone code generation (`scripts/build-validator.js`), so the bundle works under a strict Content-Security-Policy and validation is unchanged. `dist/drumdrom.min.js` goes from 250,125 bytes (81,815 gzipped) to 126,899 bytes (42,154 gzipped)
- ajv moved from dependencies to devDependencies; the generated `lib/generated/validate-schema.js` is git-ignored, built by `prepare`, `pretest`, `prelint` and `prebuild`, and shipped in the npm package
- The dist scripts bundle json5's plain CommonJS build instead of its UMD browser build, which carried core-js shims

### Added

- README "HTML pages" section: CDN usage from jsDelivr (`@dist`, or the immutable `@dist-v0.4.1`), `renderSVG` and `processAll` examples
- `examples/index.html` loads the hosted bundle by default and the local `../dist/drumdrom.js` with `?local`
- Tests: the standalone validator agrees with a fresh ajv compile and is not stale, and the built bundles render and validate with code generation from strings disabled

## [0.4.0] - 2026-10-25

### Added

- Dotted notes and dotted rests in the one voice staff layout, with Bravura augmentation dots
- Ties for sustained lanes (open hat, crash, ride), drawn below the heads; new skin key `tie_w`
- Broken beams for a sixteenth next to a dotted eighth
- Fixtures `syncopated-dotted` and `open-hat-tie`

### Changed

- Spelling now crosses beat lines where standard: a bar is spelled whole for one voice in 2/4, 3/4, 4/4 and compound meters (6/8, 9/8, 12/8, 3/8). Other meters and `voices: 2` keep the per beat spelling
- The six-eight fixture shows dotted quarters and a dotted quarter rest

## [0.3.1] - 2026-10-25

### Changed

- Unbeamed stems in the one voice layout are shorter (3.5 staff spaces plus flag allowance); beamed groups unchanged
- New skin key `stem_length_lone` (default 3.5)

## [0.3.0] - 2026-10-25

### Changed

- BREAKING (pre-1.0) staff renderer defaults to one voice with all stems up and shared stems for simultaneous notes; `config.voices: 2` restores the two voice layout. With one voice a kick and a hat on the same step are two heads on one stem, rests are drawn only where no lane sounds, and heads a second apart (crash and hi-hat) are displaced to the right of the stem with a widened ledger line. `feet_rests` applies to two voices only.

### Added

- `config.voices` (1 or 2), validated by the schema and documented in spec sections 8 and 13.

## [0.2.1] - 2026-10-25

### Changed

- Staff renderer no longer draws a rest in one voice under a note sounding in the other voice. A rest is left out when the other voice starts a note on any step it covers (spec section 13). Images and snapshots regenerated.

## [0.2.0] - 2026-10-25

### Added

- Percussion staff renderer: `renderStaff`, `renderSVG(source, { style: 'staff' })` and `drumdrom render --style staff`. Engraved with SMuFL glyphs from Bravura (percussion clef, noteheads, flags, rests, accents, parentheses, time signature), hands stems up and feet stems down as two voices, beams, a grace note for flams, ghost notes in parentheses (lighter and smaller on hi-hats), bar clearance and proportional spacing. Rhythm spelling follows the Metronome app (`lib/spelling.js`).
- `--style both` stacks the staff above the lane chart. `renderSVG`, `renderTree` and the browser `processAll` and `renderElement` take a `style` option, and `<script type="drumdrom" data-style="staff">` works.
- Skin keys for the staff (`staff_space`, `ink_color`, `staff_color` and the line widths and spacing keys, see `docs/skins.md`) in the default and dark skins.
- `lib/glyphs.js` (about 24 KB, generated by `scripts/extract-glyphs.js` from bravura-1.482) and `NOTICE-BRAVURA.txt` with the SIL OFL 1.1 text.
- Spec section 13 describing the staff rendering. The file format is unchanged.
- `scripts/render-fixtures.js` renders both styles: images and snapshots are now named `<fixture>-staff.svg` and `<fixture>-lanes.svg`. New fixture `bar-rests`.

### Changed

- BREAKING (pre-1.0): lane field `pitch` renamed to `staff`, because `pitch` reads like a MIDI pitch (that is `gm`). The meaning is unchanged: the staff position in half-spaces above the bottom line. `pitch` is now rejected as an unknown lane key.
- The default style stays `lanes`, so output of `render` without `--style` is unchanged from 0.1.0. Staff becoming the default is left for a later release.

## [0.1.0] - 2026-10-25

### Added

- Format specification, version 1 (`docs/spec.md`) with a JSON Schema 2020-12 (`schema/drumdrom.schema.json`).
- Parser and validator: `parse`, `validate`, `normalize` with all errors collected, error codes, paths, line and column.
- SVG lane chart renderer with `default` and `dark` skins, bar and beat lines, step counting, accent, ghost, open hat and flam marks.
- CLI: `render`, `validate`, `json`, stdin support.
- Browser bundle with global `DrumDrom` and `processAll()` for `<script type="drumdrom">`.
- Tests with JSON5 fixtures, committed SVG snapshots and a test that checks every example in the docs.
- GitHub Actions CI running lint and tests on Node 20 and 22.
